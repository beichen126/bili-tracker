# Provenance

This repository is a clean public implementation of the `bili-tracker` product. It does not include a private prototype's Git history, configuration, runtime data, media, cookies, logs or model weights.

## Repository-owned code

Application code, tests, documentation and configuration templates in this repository are maintained by the `bili-tracker contributors` under the MIT License.

## Runtime dependencies

Runtime dependencies are installed from package indexes and retain their own licenses. They are not copied into this repository. Optional model weights and system binaries are user-managed runtime assets and are not redistributed here.

## External integrations

Bilibili, FFmpeg, Whisper, Ollama and any future provider are integration boundaries. Their service terms, API terms, model licenses and content rights remain separate from this project's source-code license.
