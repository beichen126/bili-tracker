# Security policy

## Supported versions

Security fixes are applied to the latest `main` branch and the latest tagged release.

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability. Use the repository's private security-advisory channel when available, or contact the maintainers through the account associated with the repository. Include a reproducible description, affected version, impact, and a safe proof of concept. Do not include real credentials, cookies, private media or personal paths.

The service is designed for local use. Do not bind it to a non-loopback address unless authentication, allowed input directories, CORS and origin protections have been configured and reviewed.
